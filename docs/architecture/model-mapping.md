# Соответствие классов модели BCE коду монорепозитория

Документ фиксирует отображение всех граничных (boundary) и управляющих (control) классов диаграммы `VP-chatbot/class-diagrams/Классы - BCE.png` (а также основных сущностей и блоков сценария) на реальные файлы кода и модули NestJS / React.

## Граничные и управляющие классы (BCE)

| Класс модели | Файл(ы) | Статус | Комментарий |
| --- | --- | --- | --- |

| `PreviewChatUI` | `apps/web/src/preview/PreviewChatUI.tsx`, `PreviewPanel.tsx`, `usePreview.ts` | реализован | Выдвижная панель превью по Socket.IO (`/api/socket.io`, `/preview`): чат, кнопки, системные сообщения, перезапуск, подсветка текущего блока, панель переменных и восстановление сеанса (`PreviewChatUI` реэкспортирует `PreviewPanel`) |

| `AuthController` | `apps/api/src/auth/auth.controller.ts`, `apps/api/src/auth/auth.service.ts` | реализован | Реализован парой `AuthController` (HTTP-слой, cookie) + `AuthService` (`register`, `login`, `authenticate`, `findAuthorByEmail`, `hashPassword`, `verifyPassword`) |
| `ProjectController` | `apps/api/src/projects/project.controller.ts`, `apps/api/src/projects/project.service.ts` | частично | `listProjects`, `createProject`, `getById`, `saveScenario` и `setEnvironment` (тестовое окружение проекта через `common/environment.service.ts`) реализованы; `renameProject` и `deleteProject` — единственные оставшиеся заглушки `NotImplementedError` (до PR B) |
| `ScenarioEditor` | `apps/api/src/projects/scenario-editor.ts` | реализован | `validateScenario` и `saveScenario` реализованы (сценарий редактируется на клиенте и сохраняется целиком); неиспользуемые серверные заглушки `addBlock`, `updateBlockSettings`, `deleteBlock`, `connect`, `deleteTransition` удалены |
| `ScenarioValidator` | `apps/api/src/validation/scenario-validator.ts`, `validation.controller.ts`, `validator.module.ts` | реализован | Маршрут `POST /api/projects/:projectId/validate` и все проверки `ScenarioValidator` (`validate`, `checkSingleEntryPoint`, `checkOutputsConnected`, `checkRequiredFields`, `checkBlockFields` — шаблоны/выражения/jsonPath, `checkLoops` — предупреждение о цикле) |

| `PreviewController` | `apps/api/src/preview/preview.gateway.ts`, `apps/api/src/preview/preview-subscriber.ts`, `apps/api/src/preview/preview-cleanup.service.ts`, `apps/api/src/preview/preview.module.ts` | реализован | Socket.IO-шлюз (`namespace: /preview`, `path: /api/socket.io`, cookie `session`): `startPreview`/`sendInput`/`restartPreview` → события шлюза (`start`/`input`/`button`/`restart`), доставка `PreviewEvent` из Redis `preview:*` в комнату `chatId`; `PreviewCleanupService` удаляет просроченные контексты превью (TTL 24 ч); `stopAtUnconnectedOutput` → поведение движка (системное сообщение + подсветка) |
| `PreviewPublisher` | `apps/engine/src/preview/preview-publisher.ts`, `apps/engine/src/preview/preview.module.ts`, `apps/engine/src/dialog/ports.ts` (порт `PreviewNotifier`) | реализован | Реализует порт `PreviewNotifier` и публикует события канала `PREVIEW` в Redis pub/sub `preview:<chatId>` (`publishMessage`, `publishCurrentBlock`, `publishVariables`, `publishSystemMessage`) |
| `EventDispatcher` | `apps/engine/src/dispatcher/event-dispatcher.ts`, `apps/engine/src/dispatcher/dispatcher.module.ts`, `apps/engine/src/app.module.ts` | реализован | 16 воркеров BullMQ (по одному на раздел, `PARTITIONS = 16`), `enqueue`, `start` и `isStale` (делегирует `isStaleResponse` из `@chatbot/engine-core`); восстановление через `HttpRequestExecutor.recoverAfterRestart()` до `EventDispatcher.start()` координируется в `AppModule.onApplicationBootstrap()`; неиспользуемые заглушки `broadcast`, `takeNext` удалены |
| `DialogEngine` | `packages/engine-core/src/dialog-engine.ts` (чистая логика), `apps/engine/src/dialog/dialog.service.ts` (I/O) | реализован | Разделён на чистое ядро (`handleEvent`, `startDialog`, `restartDialog`, `runAutopass`, `executeBlock`, `followOutput`, `finishDialog`, `matchButton`, обработка HTTP-ответов/ошибок/возобновления) и I/O-слой `DialogService` (запись/обновление `http_request` с маскированием секретов, запуск отправки через `HttpRequestLauncher`, публикация превью через `PreviewNotifier`, чтение `HttpOutcome`, `loadContext` → `ContextRepository`, `findBot` → Prisma); неиспользуемые заглушки `findContexts`, `resetDialogs` удалены |
| `ExpressionEvaluator` | `packages/engine-core/src/expression-evaluator.ts` | реализован | Реализованы `evaluate`, `evaluateCondition`, `evaluateExpression`, `extractVariableNames`, `substitute` |
| `HttpRequestExecutor` | `apps/engine/src/http/http-request-executor.ts`, `apps/engine/src/http/http-request-launcher.ts`, `apps/engine/src/http/http.module.ts` | реализован | `recoverAfterRestart` переводит незавершённые `http_request` (`SENT`) в `FAILED` и ставит `REQUEST_FAILED` в очередь (вызывается в `AppModule.onApplicationBootstrap()` до старта воркеров); `ExternalApiHttpRequestLauncher` запускает отправку через `ExternalApiClient`; операции `handleResponse`/`handleFailure`/`resume` реализованы в `DialogEngine` (`@chatbot/engine-core`), а запись и отправка `http_request` — в `DialogService` |
| `ResponseParser` | `apps/engine/src/http/response-parser.ts` | реализован | `parse`, `extract`, `toText` делегируют `@chatbot/engine-core` (спринт 1 / интеграция в спринте 2) |
| `SecretVault` | `packages/vault/src/secret-vault.ts`, `apps/api/src/vault/vault.module.ts` | реализован | `encrypt`, `decrypt`, `hash` и `mask` реализованы; в `api` предоставляется глобальным `VaultModule` |

> **Примечание о заглушках `NotImplementedError`:** 14 неиспользуемых каркасных заглушек удалены (методы реализованы на другом уровне или заменены реальной логикой, включая `SecretVault.mask` и `isTokenInUse`). В кодовой базе остаются только 2 заглушки — `ProjectController.renameProject` и `ProjectController.deleteProject` (до PR B).
